## Як оновлювати

Зміну формату описуйте в моделі даних; новий сценарій — у посібнику; перенесення відповідальності між модулями — в архітектурі та карті коду. У README залишайте короткий опис і посилання. Не копіюйте сюди великі інтерфейси TypeScript: посилайтеся на їхні визначення. Нереалізовані ідеї чітко відділяйте від наявних можливостей.

# Посібник користувача

## Створення та відкриття проєкту

Запустіть застосунок за [інструкцією встановлення](../README.md). Для роботи з локальною папкою браузер має підтримувати File System Access API. Якщо вибір папки недоступний, перевірте браузер і те, що застосунок відкритий через localhost або HTTPS.

Створіть або відкрийте папку проєкту через меню застосунку. Новий проєкт потребує назви та типу: Character, Style або Concept. Тип задає початкові налаштування й пояснення; набір інструментів зараз однаковий. Під час відкриття старого проєкту застосунок може запросити тип і виконати міграцію.

Статус у нижній частині робочого простору відрізняє тимчасову сесію від збереження в папку. Якщо папку не підключено, не вважайте дані на диску збереженими. Помилка автозбереження потребує повторної спроби після відновлення доступу.

## Імпорт і відбір

Import приймає локальні файли, папки, перетягування та ZIP. Підтримуються зображення BMP/GIF/JPEG/PNG/WebP, PSD, відео MP4/WebM, TXT і JSON. Підписи TXT зіставляються із зображеннями за базовим ім’ям у межах папки. Однакові імена в різних папках не є однією парою.

Explorer показує файли проєкту. Remove Duplicates допомагає знайти схожі вихідні зображення, Analysis — дослідити зв’язки, Review — переглянути зображення, PSD та відео. Подібність є підказкою для відбору, а не гарантією дублювання чи якості даних.

Відкрийте зображення або PSD у Photopea для редагування. Save записує зміни документа; Save copy створює копію. Дочекайтеся завершення запису перед зміною проєкту. Photopea має власні комбінації клавіш усередині iframe.

## Dataset

Dataset один на проєкт і відповідає фізичній папці `dataset/`.

- **Add to Dataset** переміщує вибрані ресурси до цієї папки; для ресурсу лише в пам’яті створюється файл.
- **Remove from Dataset** переміщує їх у `src/shared/`, зберігаючи матеріали в проєкті.
- Підтримувані зміни можна скасувати через Undo/Redo. Не плутайте вилучення з Dataset із видаленням файлу в Explorer.
- Не потрібно створювати окремі `*.dataset.json`: це попередній формат, який обробляється міграцією.

Діалог формування Dataset аналізує спільні кандидати й поточний набір, дозволяє задати ціль, переглянути пропозиції та закріпити або виключити кандидати. Перевіряйте результат перед застосуванням. Coverage показує покриття множини кандидатів за ознаками, а не очікувану якість навченої моделі.

## Підписи

У Caption можна редагувати один підпис або застосувати групову зміну. Групова дія працює з вибраними файлами, а якщо вибору немає — з відфільтрованими. Перевіряйте фільтр перед застосуванням.

Для локального автотегера виберіть `model.onnx` і `selected_tags.csv` сумісного WD/Danbooru-формату. Обчислення виконує ONNX Runtime Web. Після перезапуску може знадобитися знову надати доступ до файлів моделі. Автоматичні теги варто переглянути й відредагувати.

Порожній підпис є навмисним значенням. Очищення tags не повинно автоматично повертати старий текст. Підписи зберігаються як метадані ресурсу; TXT-пари формуються під час експорту.

## Відеокадри

Відкрийте Video Frames або відповідну дію для MP4/WebM в Explorer. Можна вручну зберегти поточний кадр або завантажити модель для автоматичного відбору. Fast аналізує вибірку, Full — кожен декодований кадр. Короткі моменти можуть бути пропущені у Fast; Full потребує більше часу.

Перегляньте запропоновані кадри, виберіть папку призначення і збережіть PNG. Збереження у звичайну папку не додає кадри до Dataset: використайте окрему дію додавання. Підтримка декодування залежить від кодеків браузера. [Докладніше про Video Frames](video-frames.md).

## Експорт

1. Виберіть потрібне джерело в Export: Dataset або workspace. Режими Dataset і фізичної папки використовують файли `dataset/`.
2. Перегляньте фінальні імена та підписи. Trigger word, blacklist і усунення повторів впливають на вихідний текст.
3. Оберіть ZIP або папку призначення. Для папки використовуйте порожнє місце: конфлікт вихідного імені припиняє операцію до запису файлів.

Кожне зображення отримує відповідний TXT. Растрові файли зберігають формат, PSD перетворюється на PNG. Відео не експортується як тренувальне зображення — спочатку збережіть кадри. Скасування не прибирає файли, які вже успішно записані.

## Навігація й збереження

| Дія | Стандартна комбінація |
| --- | --- |
| Командна палітра | Ctrl/Cmd + K |
| Налаштування скорочень | ? |
| Збереження активного документа або проєкту | Ctrl/Cmd + S |
| Пошук у галереї | / |
| Вибір елемента | Space |
| Діапазон вибору | Shift + стрілки |
| Вибрати всі відфільтровані | Ctrl/Cmd + A |
| Зберегти підпис і перейти далі | Ctrl/Cmd + Enter |

Команди залежать від активної панелі; текстові поля зберігають звичайну поведінку введення. Скорочення можна змінювати в налаштуваннях.

Вкладки можна переносити між групами, панелі — докувати або робити плаваючими. Геометрія зберігається локально. Operations показує стан тривалих дій і дозволяє скасування там, де воно підтримується. Versions створює знімки проєкту; відновлення версії змінює поточні файли.

## Якщо щось не працює

| Симптом | Що перевірити |
| --- | --- |
| Немає доступу до папки | Підтримку File System Access, HTTPS/localhost, дозволи та повторне відкриття папки |
| Помилка збереження | Права запису, доступність диска, вільне місце; після виправлення повторіть запис |
| Немає PSD-прев’ю або конвертації | Чи завантажився Photopea та чи завершена попередня операція |
| Не працює автотегер | Вибрані ONNX/CSV-файли, сумісність моделі та дозволи читання |
| Відео не декодується | Підтримку конкретного кодека браузером, а не лише розширення |
| Закінчилося місце відеокешу | Очистіть відеокеш; це прибере аналізи й модель, не файли проєкту |
| Експорт повідомляє про конфлікт | Оберіть порожню вихідну папку |
| Після очищення браузера зник стан | Повторно відкрийте папку; браузерні кеші та layout не є резервною копією проєкту |

# Карта коду та перевикористання

Це довідник для вибору точки входу, а не друга специфікація. Шляхи нижче відносні до кореня репозиторію. Перед зміною перевір актуальні експорти й call sites через `rg`.

## Короткий маршрут зміни

Знайди рядок таблиці → прочитай реалізацію → знайди виклики → відкрий відповідний тест із [матриці перевірок](development.md) → внеси зміну у спільного власника. `NextApp.tsx` лише вибирає екран і монтує глобальні діалоги; `BoardScreen.tsx` збирає Board з хуків і складових `src/next/board/`; правила статусів, членства й Assemble живуть у сервісах і `src/components/build/` (див. вище). Якщо схожа поведінка вже є у сервісі, не копіюй її в компонент Board: нова копія зазвичай створить друге джерело правил.

Карту потрібно оновлювати після перенесення або перейменування модуля. Не додавай сюди повні сигнатури: вони вже визначені в TypeScript.
